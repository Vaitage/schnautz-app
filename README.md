# Schnautz Zähler

Punktezähler für das Kartenspiel Schnautz (auch Schwimmen / 31): Spieler mit eigener Farbe, Punkte mit + und −, Schnautz als Strichliste und eine Statistik aller Spiele (wenigste Punkte gewinnt).

**App öffnen:** https://vaitage.github.io/schnautz-app/

## Auf Android installieren
1. Link in Chrome öffnen
2. Menü ⋮ → **App installieren**
3. „Schnautz“ startet danach vom Homescreen, im Vollbild und auch offline

Die Daten (Spieler, Spiele, Statistik) bleiben lokal auf dem jeweiligen Gerät.
